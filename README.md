# webar-postcard

WebAR-демо на [MindAR.js](https://hiukim.github.io/mind-ar-js-doc/) и [three.js](https://threejs.org/): пользователь открывает страницу в мобильном браузере, наводит камеру на печатную картинку — и поверх неё в реальном времени рендерится 3D-модель. Установка приложений не нужна.

Сборщиков нет: чистый HTML плюс библиотеки с CDN.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | вся логика: трекинг, загрузка модели, экранный журнал диагностики |
| `assets/targets.mind` | скомпилированные точки отслеживания картинки |
| `assets/model.glb` | 3D-модель (сжата `EXT_meshopt_compression`) |
| `ar-target.png` | сгенерированный тестовый таргет 1024×1024 |

## Как заменить картинку или модель

**Таргет.** Загрузите изображение на [mind-ar-js-doc/tools/compile](https://hiukim.github.io/mind-ar-js-doc/tools/compile), скачайте `targets.mind` и положите в `assets/`.

Хороший таргет — контрастный, с обилием **неповторяющихся** деталей и асимметричной композицией. Плохо работают QR-коды, орнаменты и любые регулярные узоры: детектор путает одинаковые участки между собой. Компилятор показывает найденные особые точки — их должно быть много и по всему полю.

**Модель.** Положите `.glb` в `assets/`. Страница сама вычисляет габариты, вписывает модель в ширину картинки и разворачивает её так, чтобы она стояла над открыткой, — подбирать масштаб вручную не нужно.

Подключены декодеры Draco и meshopt, так что сжатые обоими способами файлы открываются без правок кода.

### Про координаты при экспорте из CAD/BIM

Экспортируйте модель, предварительно переставив её в **начало координат**. Если вершины лежат в сотнях тысяч или миллионах единиц (обычное дело при географической привязке в Revit и подобных), точности `float32` перестаёт хватать: при значении около 3 000 000 различимый шаг составляет уже 0,25 единицы, и мелкие детали необратимо теряются ещё на экспорте. Никакая последующая обработка их не вернёт.

## Диагностика

Внизу страницы выводится журнал: загрузка библиотек, старт камеры, прогресс загрузки модели, события `ТАРГЕТ НАЙДЕН` / `таргет потерян`, параметры видеопотока. Ошибки — красным. Это первое, куда стоит смотреть, если что-то не работает.

## Запуск

Локально — см. [serve.md](serve.md). Камера требует защищённого контекста: годится `https://` либо `localhost`. По адресу вида `http://192.168.х.х:8000` браузер камеру не даст.

## Деплой

Подходит любой статический хостинг с HTTPS: GitHub Pages, Netlify, Vercel. После публикации сгенерируйте QR-код на итоговый URL и разместите его на визитке.
